# AI 工具导航网站（可直接运行版）

根据《AI 工具导航网站建设方案 V1.0》实现的完整可运行原型。纯原生 HTML/CSS/JS，无需安装依赖、无需构建、无需服务器。

## 运行方式

**最简单**：双击 `index.html`，用浏览器打开即可。

**本地服务器**（可选，推荐用于测试站点地图/SEO）：
```bash
cd ai-nav-site
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 已实现功能

### 前台
- **首页**：搜索、8 大分类入口、精选工具、最近收录、横幅广告位 A
- **分类页**：分类说明、工具列表、分类横幅广告位 C、排序
- **工具详情页**：用途/功能/场景/官网/定价/核对日期/相关工具、详情广告位 D
- **搜索**：覆盖名称、简介、标签；与分类组合筛选；命中数量；无结果状态
- **我的收藏**：浏览器本地保存（localStorage），刷新保留，即时增删
- **提交工具**：表单校验后进入待审核队列
- **商务合作**：广告位规格、投放流程、统计口径、联系方式

### 后台（入口右上角「管理后台」，演示账号 admin / admin123）
- **概览**：内容、待审核、投放、统计概况
- **工具管理**：新增/编辑/上下架/删除、精选排序、核对日期
- **分类管理**：新增/编辑、顺序、启停
- **提交审核**：通过（自动生成工具）/拒绝/删除
- **广告管理**：新建/编辑计划、广告位与页面、优先级、排期、状态（草稿/待投放/投放中/已暂停/已结束）
- **投放统计**：按展示/点击/点击率分组，导出 CSV
- **站点设置**：站点名称、描述、商务联系方式
- **备份恢复**：导出/导入 JSON，重置初始数据

### 广告系统
- 四类广告位（A 首页横幅 / B 赞助工具卡 / C 分类横幅 / D 详情广告），均带"广告/赞助"标识
- 按北京时间校验排期：未来计划不上线、到期自动下线、暂停后停止新页面投放
- 同优先级等概率选取，同一页面访问内素材保持不变
- 展示量口径：50% 面积可见连续 1 秒且页面可见，同一页面实例去重
- 点击去重，点击率 = 点击量 ÷ 展示量，展示量为零显示"暂无数据"

## 数据存储

所有运营数据保存在浏览器 `localStorage`，键名前缀 `nav.`。清理浏览器数据会重置；请用后台「备份恢复 → 导出 JSON」保存。

## 上线到生产环境的说明

本版本为**纯前端演示原型**，用于验证交互与运营流程。正式上线按方案第六/八章还需：
- 服务端管理员鉴权（当前为前端校验，仅演示）
- 关系型数据库 + 文件存储（当前为 localStorage）
- 独立广告接口按广告位/页面/时间返回有效计划
- 每天自动备份、公开表单限频、上传图片类型校验、站点地图与规范链接

演示账号与示例联系方式请在后台「站点设置」中替换。

## 部署到 GitHub + Vercel

本项目已包含 `vercel.json`，Vercel 会自动识别为静态站点，无需额外构建配置。

### 方式一：Vercel 一键部署（推荐）
1. 把本目录推送到你的 GitHub 仓库（见下方 Git 命令）。
2. 打开 Vercel 导入链接（把 `<用户名>`、`<仓库名>` 换成你的）：
   `https://vercel.com/new/clone?repository-url=https://github.com/<用户名>/<仓库名>`
3. 用 GitHub 账号登录 Vercel，点击 **Deploy**。Vercel 自动检测静态站点并部署。
4. 之后每次 `git push`，Vercel 都会自动重新部署。

### 方式二：本地 Vercel CLI
```bash
npm i -g vercel
vercel login
vercel --prod
```

### 推送到 GitHub 的命令
```bash
cd ai-nav-site
git init
git add .
git commit -m "feat: AI 工具导航网站"
git remote add origin https://github.com/<用户名>/<仓库名>.git
git branch -M main
git push -u origin main
```

> 仓库建议设为 Public，方便 Vercel 导入；如需私有，Vercel 同样支持授权导入。
